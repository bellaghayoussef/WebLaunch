## How to send the demo link (so owners can open it on their phone)

The demos are HTML files. To turn them into a shareable link, pick one (all free):

1. **Netlify Drop** — go to app.netlify.com/drop and drag the restaurant's folder in. You get an instant link like `mama-rozie-demo.netlify.app`. Easiest option.
2. **GitHub Pages** — push the `demos/` folder to a GitHub repo and enable Pages.
3. **Cloudflare Pages / Vercel** — similar drag-and-drop or connect-a-repo flow.

Tip: give each demo a clean subdomain with the restaurant's name (e.g. `mamarozie.netlify.app`) — it looks far more professional than a raw file, and seeing their own name in the URL makes owners take it seriously.
